# MusicWall – Downloads

Hier stehen die signierten Installations- und Updatepakete von MusicWall bereit.

Die [Releases](https://github.com/neomorph77/musicwall-releases/releases) enthalten
je Version vier zusammengehörige Dateien: das ZIP-Paket, die SHA256-Prüfsumme,
das Release-Manifest und dessen Signatur. Versionshinweise und die
Installationsanleitung liegen im jeweiligen Paket.

Bestehende Installationen behalten ihren lokalen Update-Prüfschlüssel.
Der öffentliche Downloadkanal ändert die signierte Produktidentität nicht.
Die Pakete enthalten den für Installation und Betrieb vorgesehenen Quellcode;
private Entwicklungsunterlagen und Zugangsdaten gehören nicht zu diesem Kanal.
